# Proposta landing

Preventivo interattivo per il portfolio video: selezione della landing, business card, gestione video e PDF riepilogativo con data.

## Pubblicazione

Pagina statica senza dipendenze. Per GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Il pulsante WhatsApp scarica il PDF e apre la chat; il documento deve essere allegato manualmente.

## File

- `index.html`: interfaccia
- `data.js`: testo e prezzi della proposta
- `app.js`: scelte, riepilogo e condivisione
- `pdf.js`: generazione PDF locale

Le scelte non vengono inviate a un server.
